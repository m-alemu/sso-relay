SSO Relay

Forwards SSO callbacks to a local or LAN instance of the app, keeping the route and every SSO parameter (#/login?SSORequestToken=…).

Replay a callback

Paste the URL the IdP redirected to (e.g. the digitalinvestor-intg…/app/#/login?SSORequestToken=… one). Its host and path are swapped for the target. Tokens are short-lived, so paste it right away.

Direct callbacks

To skip the paste step, register this page's URL as the partner's return URL: . Callbacks are forwarded automatically, to RelayState if it's allowed, otherwise to the saved target.

Only localhost and private-network targets are accepted, unless the host is added to EXTRA_ALLOWED_HOSTS in this file.
